## Quem eu sou

Tenho 3 empresas reais como clientes hoje — prospectei, apresentei a proposta, fechei e
entrego mensalmente, sozinho. Comecei a vender antes de ter currículo para isso, e é esse
mesmo caminho que me trouxe para dados: em todo projeto o que o dono do negócio realmente
quer saber é *o que os números estão dizendo*.

Agora quero fazer isso em tempo integral, dentro de um time de dados, aprendendo com quem
já faz em escala.

**O que eu trago para um time de dados:**

- **Autonomia comprovada** — nenhum dos meus projetos começou com alguém me dizendo o que
  fazer. Todos começaram com uma reunião que eu marquei.
- **Tradução de negócio para dado** — converso com o dono da empresa e com o banco de
  dados. A pergunta certa vale mais que a query bonita.
- **Entrega recorrente** — mensalidade que continua entrando é a única avaliação de
  desempenho que não admite discurso.
